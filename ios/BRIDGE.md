# Native contract additions

CAMERA UPDATE: Native.call('camera', {purpose:'expiry'|'barcode'}) presents a native AVFoundation preview, never getUserMedia. Returns {image:'data:image/jpeg;base64,...'} for photo, or {barcode:string} when the barcode scanner detects a code. Cancellation/background rejects with a readable error; permission denial is explained in the native UI with a photo-library fallback. Do not assume success on dismissal. Camera has close, capture, torch and photo-library picker. Expiry photos are normalized upright to <=2048 pixels long edge, JPEG <=5 MiB. Barcode photo/library capture runs native Vision barcode recognition and returns barcode text or a clear no-barcode rejection, never an image in barcode mode. Native barcode metadata supports EAN-8/EAN-13/UPC-E/Code128/QR. Either storage mode can capture; no network used.

Each request independently reads localStorage.getItem('expiry_mobile_mode_v1') from the trusted bundled main document via WebKit; only exact 'cloud' permits native transport. Native defaults LOCAL on every navigation and cancels all sessions on mode/navigation changes. An optional Native.call('mode',{mode:'local'|'cloud'}) action provides immediate cancellation and returns {mode}, but cannot bypass the trusted document storage check. This matches mobile-web/boot.mjs without requiring its modification.

All actions use window.webkit.messageHandlers.native.postMessage({id,action,...}); window.nativeReply(id,result,error). Request body/reply body and export data are strict base64, not UTF-8. Max decoded request/response/export/OCR image: 20 MiB; max four network requests in flight. Export supports safe basenames ending .json or .csv only. OCR supports PNG/JPEG/HEIC image data URLs. HTTPS URL path cannot contain percent escapes (query escapes allowed); storage should use simple UUID filenames. Only exact approved Supabase host and four endpoint prefixes allowed. No redirects or cookies. Network transport errors reject, HTTP errors preserve status/body.
